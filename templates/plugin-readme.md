# 插件使用说明模板

根据真实包类型选取内容，不要求保留全部标题。不要将本模板直接发布成用户文档；删除编辑提示，填入实际事实。写作要求见 [文档规范](../docs/documentation-standard.md)，官方依据见 [来源映射](../docs/source-map.md)。

## 能做什么

说明用户或 Agent 能完成的动作、适用场景和主要限制。用可观察能力开头，不用内部模块名单代替功能说明。

## 前提与安装

说明已验证的 DSH 版本、平台和必需依赖。核对实际 manifest：bundle 说明加入 profile 的路径，可加载插件说明挂载方式，普通库说明导入方式。

写出已验证的完整操作路径，包括工作目录、输入值、安装后应看到什么、如何确认成功。未执行过的命令留在开发计划中；需要说明待验证路径时明确标注。

## 使用与配置

先给一个能完成目标的最短例子，再解释影响结果的配置。配置类型和默认值来自实际 schema，避免重复维护完整字段表。

说明依赖不可用、参数错误和操作失败时的表现及恢复方式。涉及网络或后台任务时交代完成、取消或超时的含义。

## Agent 能看到什么

若提供工具或 Skill，说明何时应使用、主要输入、规范返回值、失败结果以及可见副作用。工具名和参数从实际定义获取；完整工具目录已生成时链接它。

不提供模型能力时直接说明没有，不编造工具或模型效果。间接组合其他插件时标明实际能力所有者。

## 数据与生命周期

涉及数据时说明保存位置、重启行为、升级兼容及卸载保留/清理约定。存在订阅或进程时说明禁用、退出和恢复行为。

## 已知限制与验证范围

记录用户需要知道的真实限制，链接实际验证记录。区分已验证的系统、主题、安装方式与仍未覆盖的路径。

## 开发入口
