# 素材库助手

## 目标与验收

用户要求：插件安装后自带完整 Skill，让 DSH 对话 Agent 导入文件夹、按画面整理和搜索素材。使用原生工具与 Skill 注册表，不要求另外安装 MCP 或复制技能目录。

验收：安装包包含 Skill；宿主可发现、加载、禁用该技能与工具；递归导入保留源文件、按内容去重、可暂停/恢复/重试；Agent 能获得真正的图片附件和视频抽帧；批量修改复用现有收藏夹和标签；后台任务可在任务中心操作。完成/取消的任务不常驻界面。

## 接口依据与边界

目标 DSH 0.2.1-rc.3。以安装版本 `dsh-skill`、`dsh-tools`、`dsh-attachment` 的类型及 README 为准：`ctx.skills.register` 注册 bundled Skill，工具通过 `defineTool` 与 `ctx.tools.register` 注册，图片由 `ctx.attachments.saveImage` 生成持久附件。宿主负责工具权限及模型选择。文本模式不能推断图片内容；Embedding 只用于检索，不能冒充画面描述。

## 实现结构

- `skills/asset-library-assistant/SKILL.md`：选库、扫描、导入、看图分类、检索及失败恢复工作流，随 npm/Git 包分发。
- `src/host/assistant.ts`：原生工具与 Skill 注册，结构化输出；不向模型输出凭据或 Base64。
- `src/host/imports.ts`：本机路径扫描与持久导入队列。记录每文件大小、修改时间、上传 ID、结果与错误；恢复时检查源文件变化，复用上传检查点和 SHA-256 去重。
- `src/host/service.ts`：UI 和工具共同的业务入口，提供批量元数据编辑、抽帧和索引管理。原件仍经过现有导入、预览、S3 和索引链路。

扫描限制为每批 10,000 个目录条目，跳过符号链接、隐藏目录、库内部目录及不支持格式；超过上限明确失败。支持本机文件和文件夹，不自动爬取远程 URL。导入成功与 AI 索引成功分开统计。导入任务留在本机队列文件中，不写入 ZIP；已入库素材和元数据沿用现有迁移协议。

## 验证路径

执行类型检查、导入/批量编辑/附件/队列测试、构建、分发与官方兼容检查。在独立 DSH_HOME/profile 安装包，验证技能目录和实际工具注册/调用；不改个人 profile。真实模型视觉效果、NAS 故障和 Windows 本地路径依赖相应环境，不能用模拟测试宣称全覆盖。

- 类型检查、构建及安装包检查通过；官方兼容检查接受 DSH `0.2.1-rc.3`，无需版本豁免。Skill 创建器格式校验通过。
- 29 项测试通过，包括递归导入、内容去重、源文件变化检查、中断后继续、批量编辑事务、原生 Skill/工具生命周期、真实图片附件，以及已有 ZIP 和 S3 迁移回归。
- 回归测试发现并修复后台预览任务使用旧快照覆盖新标签的问题，导入后的整理结果可保留。
- 在独立 `creative-test` profile 通过 DSH 官方安装器安装 `0.7.0` 本地包，确认安装内容包含 Skill，不执行插件构建脚本。
