# Base 状态

日期：2026-09-18。

## 已建立

- 通用 AGENTS 开发入口、手写开发 Skill 和自动生成的官方参考 Skill。
- 按新项目、现有功能、小修复、评审/调研区分的准备流程。
- 按需更新长期规则、设计与任务记录的文档约定。
- 明确的文档内容要求、契约字段、状态证据、更新规则，以及官方来源映射。
- Host、Client、打包与验证参考，以及固定提交的官方资料索引。
- 可选项目说明、变更计划、规则补充、插件使用说明模板，以及一份明确标注未实现的完整准备示例。
- 无第三方依赖的本地文档检查脚本与针对其错误检测的测试。
- 官方文档同步生成器：全量扫描仓库 Markdown/MDX，保留各语言原文、分级索引、覆盖报告、许可证与哈希；工具与配置在 Skill 内，可独立携带。

没有预设业务领域、源码目录、前端工具链、数据库或单/多包结构。首次业务任务根据需求选择。
