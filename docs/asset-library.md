## 当前交互：侧栏、搜索首页与键鼠接续

0.6.5 微调：收藏星标不因已收藏而常驻，仅悬停或键盘聚焦可见，触屏保留可见入口；搜索防抖和请求等待用与结果行相同结构的骨架占位，旧结果不参与导航。主列表与搜索工具栏在有条件时显示重置，面板标题栏保留重置按钮，清空条件不改变排序。修改范围为 Client，验收检查收藏按钮可见性、加载布局、键盘入口和两个位置的筛选重置。

侧栏通过 DSH 原生布局接口展开/折叠，折叠时保留图标导航。收藏夹导航整行等宽，背景与焦点状态统一由外层承担；内部文字、菜单按钮不叠加背景。

搜索首次打开或彻底关闭后再次打开，查询为空并显示最多 8 项最近导入；空查询始终使用本地普通查询，不调用 AI。弹窗高度随内容收缩，空库及无结果显示紧凑空态。查询时固定相关度；预览返回保留查询、结果及焦点，彻底关闭搜索清空查询。

素材网格和搜索结果各共用一个当前项，鼠标真实移动接管，方向键从该位置继续。相同指针坐标不重新抢回键盘选择，输入框的文字编辑不被悬停打断。卡片以灰色背景和细灰边线标识当前项，搜索结果仅用灰色背景。验证证据见 0.6.4 记录。

## 0.6.0 搜索键盘与收藏夹统一

目标：搜索固定相关度，普通列表仍可排序；网格按实际行列处理方向键，搜索按结果列表导航，Space/Enter 打开预览，Esc 保留搜索词、结果及焦点。输入框中的空格和左右键继续用于文字编辑。收藏状态改为收藏夹归属的汇总，默认收藏夹固定存在，旧收藏无损迁入；用户收藏夹仍可管理。

实现范围：Client views 与键盘导航帮助函数；Host 统一 editAsset/setCollections/updateAsset，SQLite v3 增加默认夹标志，ZIP 携带该标志并兼容旧包。沿用 DSH 0.2.0-rc.2 的 Modal/Menu/locale/token，不修改宿主。

验收：自动测试覆盖旧库迁移幂等、默认夹保护、收藏状态一致、ZIP 往返和文字相关度；实际宿主验证网格与搜索方向键、预览返回焦点/查询保留、搜索无排序控件及收藏选择器。实际升级、备份结果与交互证据见验证记录的 0.6.0 条目。

## 约束与验收

用户选择：名称“素材库”；DSH 原生插件；本地托管多库，可整体迁移；火山多模态嵌入；搜索弹窗右侧 AI 开关；可靠队列与提示。最新反馈要求卡片更精细、右侧详情、可创建收藏夹。

项目选择：库 → 一层逻辑收藏夹，多对多引用、不复制文件；标签描述内容，底层文件目录不参与用户分类。

## 职责与接口

src/shared/contracts.ts 是 Host/Client 共用的 Zod 契约与 Remote 描述表。src/host/index.ts 注册 Cordis 服务、Host Typert invocations、credentials 适配与 Agent 工具。src/host/service.ts 是 UI、工具唯一业务所有者；storage.ts 管 SQLite/锁/版本，media.ts 管 FFmpeg，ark.ts 管 HTTPS 嵌入与错误分类。

Client index.tsx 管 slots/store/订阅生命周期；views.tsx 管原生界面；CSS Modules 使用宿主 token。使用 sidebar.panellist 与同 ID main，进入时注册优先级 -50 的根 sidebar，离开释放；返回选择之前的 panel ID 或 null 会话。右侧素材详情属于插件主面板布局，不覆盖宿主会话工具侧栏。公共 Modal/Button/Input/Menu/Switch/Toast 来自 DSH Primitives。

接口通过共享表派生显式描述，Host typert.register(invocations)，Client remote.$mount。它是本项目选择，不是 Typert 生成器产物；不另外启动 REST 服务。

asset_library_list 返回打开的库；asset_library_search 接收 query、可选 library_id 与 ai（默认 false），返回 ID、相对路径和视频时间。UI 与工具复用检索服务。真实对话中的工具调度尚未测试。

## 存储与恢复

库持有文件、SQLite 元数据/向量/任务/通知。机器配置只持有库位置及非密钥设置，credentials 保管密钥。数据库版本 2 增加收藏夹与多对多关联，版本 3 增加固定默认收藏夹并一次迁移旧收藏，旧库自动迁移，不支持降级。收藏状态从归属推导；ZIP 携带默认夹标志，导入旧 ZIP 时补建默认夹并迁移旧收藏。

导入分块校验偏移，写 staging 并刷盘；finish 先保存预期落点，再 rename，最后事务登记素材与任务。相同内容按 SHA-256 去重。同库写入串行化；关闭等待在途写入和处理终止再 checkpoint。

队列 queued/running/paused/retrying/completed/failed/cancelled，默认并发 2、最大 4，默认最多 3 次重试；网络/429/5xx 退避并尊重有界 Retry-After，鉴权/格式直接失败。每片段保存向量；URL、模型、分段长度构成指纹，配置变化重新准备帧，不混用索引。

退出中止请求与 FFmpeg，running 回 queued，paused 保持暂停；再次启动恢复。意外持久化错误隔离该库并提示不可用。客户端离开不停止后台索引。通知持久化，进入插件后显示。

检索当前使用 SQLite JSON 向量逐条归一化余弦评分，关键词加权，每素材取最佳片段；大库加速是后续事项。使用边界统一见 [README](../README.md)，真实证据见[验证记录](asset-library-verification.md)。

用户要求：响应式保留视频比例；空格预览；有无标签等高卡片；取消详情保存按钮；大量收藏夹易选；Esc 分层返回；星形 AI 开关和激活渐变；库菜单与触发按钮等宽。

实现边界：复用 Primitives Modal/Menu/IconSparkleRegular，核对目标包声明及本地宿主实现，不新增独立 UI 框架。主区宽度不超过 780px 时详情覆盖主区，宽屏并排；缩略视频 contain，卡片媒体区 16:9，正文和标签占位固定。详情和快速预览使用原图/视频固有比例。

客户端 asset-editor.ts 独立持有编辑草稿，按素材串行提交、500ms 防抖，收藏/归属立即提交。页面切换不销毁在途写入；失败不回滚用户输入，支持重试。浏览器 localStorage 保存尚未确认的修改，刷新后提示手动重试，不擅自重放。新增 editAsset 共享接口对可选字段局部更新，在 Host 校验收藏夹归属后事务提交，避免全表单覆盖其他修改。关闭库前等待保存，错误时保留打开状态。

验证路径：类型检查；自动保存串行/并发编辑/失败恢复/页面选择无关测试；部分更新与非法归属事务测试；安装隔离宿主后验证卡片尺寸、视频比例、键盘层级、菜单宽度、自动保存持久化、收藏夹筛选和星形状态。实际结果维护于验证记录。

## 0.4.0 搜索与筛选调整

用户要求与验收：外层隐藏标签、详情隐藏内部路径；空格快速查看只保留细标题栏，媒体保持比例；库选择器使用最右侧 ChevronRight；取消搜索提交按钮，输入后自动更新；主列表和搜索提供可展开的筛选侧栏。

使用已核对的 DSH 0.2.0-rc.2 Primitives Modal.headless、IconChevronRightOutlineRegular、IconSlidersTwoOutlineRegular。复用 Modal 的焦点、遮罩和 Esc 管理。筛选包括类型、收藏、多个收藏夹（任一）、标签（全部）、导入时间、当前模型索引状态及排序；共享 search 契约在 Host 分页前处理，不创建独立 REST 接口。筛选视图状态归 view-store，filters.ts 负责向请求映射。

自动搜索是输入防抖触发，普通 250ms、AI 700ms；不会定时重复请求同一查询。继续输入、组合输入或关闭弹窗取消旧请求；结果提交前检查中止状态，避免旧结果覆盖。相同 AI 文本继续复用 Host 查询向量缓存，筛选变化无需重复生成向量。输入法组词期间不提交，回车可立即完成查询。空 AI 查询不调用模型。

验证：Host 组合筛选、当前模型索引过滤、排序及分页测试；真实宿主检查筛选面板、重置与空态、自动文字搜索、缺少密钥提示、紧凑预览、菜单箭头及隐藏标签/路径。真实火山 API 与检索质量仍未覆盖。

## 0.5.4 原生设置、S3 和 ZIP

用户确认：S3 保存原文件及预览，索引留本机，通过 ZIP 迁移；本地模式显示文件夹选择，S3 模式才显示连接表单。原生设置通过 settings.section 注册，复用宿主导航与弹窗。替换侧栏不声明或占用宿主已有的 sidebar.settings。0.5.8 起移除素材库独立设置按钮及临时 launcher，配置统一从 DSH 原生设置进入。

objects.ts 使用 AWS SDK v3 的私有对象读取和 multipart Upload；存储绑定在 library.json，S3 库使用 manifest v2，旧版本拒绝打开以免误认成本地库。凭据以 Endpoint/region/bucket 的散列为键单独保存。上传属于索引任务的 upload 阶段，成功后才移除本地原件；失败保留，支持现有重试与取消语义。

archive.ts 用 yazl/yauzl 做 ZIP64 流式文件处理，白名单路径、禁止符号链接/重复项、容量上限与 SHA-256 校验。目录快照在 SQLite 同步事务内读取，导出暂缓该库的索引写入；导入先在临时目录构建完整库，再一次 rename 发布，带操作身份以支持发布后中断的重试。新库身份独立，保留素材身份、集合引用与向量。

transfers.ts 是机器级持久迁移队列，单任务执行，页面关闭不影响后台。进程中断变为暂停，显式重试重新处理；失败保留可读原因，不把迁移状态混进便携库。snapshot 统一返回状态和通知。settings.tsx 与 transfers.tsx 负责客户端表单和进度，设置普通字段自动保存，密钥需明确保存。

实施依据与记录见 [存储升级](storage-upgrade.md)，验收证据见 [验证记录](asset-library-verification.md)。真实云端供应商与 Windows 保持未验证。
