# 官方文档生成 Skill

状态：已实现并完成下列验证。用户要求开发资料全部收录，生成器随 Skill 携带，可重新运行更新。

## 目标与验收

| 验收 | 行为与验证方式 |
| --- | --- |
| 文档齐全 | 枚举官方完整 Git 树，全部 Markdown/MDX 均纳入，包括各语言、包级说明、Cordis API、全部子系统和官方 Skill；以源树清单对比证明零遗漏 |
| 原文完整 | 除阅读版外，逐字节保存原文；每次下载与 Git blob SHA 比较，记录 SHA-256 |
| 独立携带 | 脚本、配置、链接解析器与本地检查全部位于 Skill 内，删除 base 后仍能检查并重新生成 |
| 自动发现 | 新目录、新文档自动纳入兜底分类；主题配置漏收时报错，不能靠固定篇数通过 |
| 按需阅读 | 主题入口及按来源目录细分索引；历史记录、提案、测试快照分开，不作为当前项目指令 |
| 更新与保护 | 最新或指定提交来自同一快照；相同输入无写入，失败不替换旧版，保护本地正文修改及并发输入编辑 |

## 设计与文件影响

- 真实生成器移动到 `.agents/skills/dsh-official-reference/scripts/`，根 `scripts/sync-official-skill.mjs` 保留兼容转发；来源配置只维护 Skill 内一份。
- 全量模式保留所有语言，分类不限制总收录范围；新增覆盖清单与机器校验。
- 阅读版保留出处并改写相对链接；`originals/` 另存未改写正文，以 `.txt` 后缀避免上游规则自动加载。
- 符号链接在 Git 快照内解析，不创建本地链接；拒绝越界、循环与缺失目标。
- 仓库许可证及声明文件归档，依赖源码、图片等非 Markdown 资源仍指向官方固定提交。
- 同步器自带可编辑输入，但生成正文仍受所有权和内容哈希保护。完整候选校验后原子替换，失败回退。
- 没有新增业务插件或固定业务目录；完整资料仍由手写开发流程按需求选读。
